# UI 精细化设计规格（Apple 式微雕）

日期：2026-08-11
状态：已与用户逐项确认
基础：`2026-08-11-ui-redesign-design.md`（上一轮重构已交付，本文档在其上做精细化增补）

## 1. 目标

在已交付的"零 Material 自建设计系统"基础上，将 UI 从"组件齐全"提升为"产品级精美"。方向：**苹果式微雕**——克制的蓝、细分隔线、大留白、字重层次，靠精度取胜。页面元素更丰富：行内元数据、侧边栏增强、smart 视图分区、详情页丰富、氛围与动效。

不做：键盘快捷键、通知/重复/旗标数据功能（仅展示层）、数据迁移（直接改 schema）。

## 2. 数据模型改动（最小）

`todo` 表加一列（直接改 schema，无迁移）：

- `flag INTEGER NOT NULL DEFAULT 0` —— 旗标（0/1）

**已存在、无需新增**：`completedAt`（模型/表/测试均有，完成时写入、取消完成置 null）；时间——`due_date` 是完整 Instant，quick-add 解析的"15:00"已存入并显示（`formatDueDate` 输出"今天 15:00"），无需 dueTime 列。

UI 改动：TodoItem 增加 `flag: Boolean`。仓库新增 `setFlag(id, flag)`；MainViewModel 新增 `toggleFlag(item)`。

**时间选择**：RemDatePicker 弹窗增加时间行（时/分步进器 + "无时间"选项），改 `due_date` 的时间部分（保留现有 date+time 语义，无时间 = 00:00，展示层不显示）。

## 3. 行内元数据（双行式，已确认）

列表行（今日/各列表/搜索）：

```
第一行  [勾选圈] 标题 ——— ——— [旗标⚑] [时间徽章]
第二行  备注预览（灰字，超长省略） [子任务计数 ⌄ 3]（右侧）
```

- 行高 ~52dp（第一行 20dp + 第二行 16dp + 上下 padding 16dp）
- **时间徽章**（标题行右端）：彩色胶囊，圆角 6dp，字号 11sp：
  - 今天：`#FFD60A` 20% 底 / `#B25000` 字（亮色）；暗色 `#FFD60A` 25% 底 / `#FFD60A` 字
  - 明天：中性灰 `#C7C7CC` 20% 底 / 系统灰字
  - 已过期：`#FF3B30` 15% 底 / `#FF3B30` 字 + "逾期"文案（如"昨天 · 逾期"）
  - 有 dueTime 时显示"今天 15:00"格式，仅日期时显示"今天"
- **旗标**：标题行右端、时间徽章左侧，`#FF9500` 填充旗形图标（复用 RemIcons 新增 FlagIcon），宽 16dp
- **子任务计数**：第二行右端，`⌄ 3` 样式，`#C7C7CC`（暗色 `#48484A`），无子任务时不显示
- **完成时间**：已完成的条目勾选圈实心 + 标题划线置灰（现有），其第二行显示"已完成 今天 15:00"（完成时间），代替备注预览
- **逾期标红**：时间徽章红色 + 勾选圈边框红色（现有行为保留）

无时间、无备注、无子任务的条目：只显示第一行，行高保持 52dp 内（第二行隐藏）。

## 4. 列表页头部 + Sticky 分区（已确认）

仅 **smart 视图**（今天 / 已完成 / 搜索）分区：

- **过期 / 今天 / 以后**（今天视图）；**今天 / 以后**（已完成视图按完成时间）
- 分区标题：13sp 600 字重，左侧计数胶囊（同时间徽章配色），右侧 1px 横向细线延伸至行尾
- 分区内容：**白卡片浮于灰底**——卡片背景 `#FFFFFF`、圆角 10dp、1px 边框 `#EEE`（暗色：`#2C2C2E` 底、`#3A3A3C` 边）、微弱阴影 `0 1px 3px rgba(0,0,0,0.04)`（暗色无阴影改高光边）
- 分区卡片间 12dp 垂直间距；列表页底 `#F6F6F8`（统一窗口底色）
- 吸顶：分区标题 sticky，滚动时卡片上缘与标题有 1px 过渡分隔

**列表头**（所有视图一致）：

```
[大标题 28sp 700]  [计数胶囊] [＋按钮 26dp 圆角6]
[副行 13sp 灰：日期（smart）或"X 项待办 · Y 项已完成"（普通列表）]
```

- ＋按钮：浅灰底 `#F2F2F7` 圆角 6dp，hover 变 `#E5E5EA`，点击新建（当前 quick-add 行为保留）

**普通列表**（非 smart）：不按时间分区，但"待办 / 已完成"两组各用一个白卡片（待办在上，已完成在下，中间 12dp 间隔）；已完成卡片头部为"已完成 X 项"，初始折叠态可展开（复用现有 expanded 逻辑，改为每列表独立记忆）。

## 5. 侧边栏增强（已确认）

- **分组标题**："我的列表" 12sp 600 字重，带折叠/展开箭头（点标题折叠该组所有列表，仅视觉折叠）
- **计数徽章**：每列表行尾待办计数，10sp 灰字；选中时深色字
- **今天红色计数**："今天"行尾红色计数胶囊（`#FF3B30` 底白字，圆角 8dp，数字为 0 不显示）
- **hover 操作按钮**：行尾 hover 显示"＋"（新建，跳转列表并聚焦 quick-add）；选中列表行 hover 显示"删除"（垃圾桶图标，点击走现有删除确认对话框）——两按钮在行尾垂直排列小图标 16dp
- **搜索框常驻**：侧边栏顶部搜索框（现有 RemTextField 样式），删除后恢复为"＋ 新建列表"按钮与分组标题
- 列表项行高 30dp；删除按钮 hover 变红

## 6. 详情页丰富（已确认，结合版）

```
[标题 17sp 600 内联编辑]        [时间徽章 11sp（与标题同行右侧，可点击清除）]
[备注块：灰字 #8E8E93 13sp，浅灰底 #F8F8FA 圆角 6dp，点击进入编辑态]
───────────────────────────────（1px 分隔线）
[⚑ 旗标]  （点击切换，选中态 #FF9500 实心）
[🗓 日期行] 今天 15:00 · 点击修改（RemDatePicker 弹窗底部加时间行：时/分步进器 + "无时间"选项，改 due_date 时间部分）→ 显示"今天 15:00"
[▤ 列表行]  工作 →（现有切换列表对话框）
[☑ 子任务] ⌄ 3（折叠显示行数；点击展开子任务区）
[✓ 完成时间]（已完成条目显示）
[创建时间]（副行灰字，仅"已完成"视图/详情显示"创建于 8 月 3 日"）
───────────────────────────────
[底部操作区] 左：移到列表（现有对话框）右：删除（现有确认）
```

- 每行 13sp，图标 16dp `#8E8E93` 引导；行间 1px 细分隔线 `#F0F0F2`
- 旗标、日期、列表、子任务四行高度 36dp 可点击整行
- 备注块初始显示为灰字预览；点击进入编辑（现有行为，仅加底色圆角质感）

## 7. 氛围与动效（已确认）

- **空状态**：极简线条插画（方案 B）——斜置圆角卡片线稿 + 勾，2px 边框 `#D8D8DE`，96dp；文案 15sp 600 + 13sp 灰副行。三种：无待办 / 搜索无结果（"没有找到结果"）/ 垃圾箱
- **面板过渡**：详情面板切换列表时 150ms 淡入 + 4dp 上滑（AnimatedVisibility slideIn+fadeIn）
- **勾选渐隐**：勾选时行内容 200ms 渐隐 + 高度收缩（animateContentSize），随后移除
- **细滚动条**：桌面端 Scrollbar 宽 6dp、滑块 `#C7C7CC` 30% 透明度、圆角 3dp、hover 60%
- **窗口底色**：三栏背景统一 `#F6F6F8`（暗色 `#1C1C1E`）；侧边栏白（暗色 `#1C1C1E`）不变
- **数字滚动**：计数徽章变化时 150ms 淡入淡出（可选，低优先）

## 8. 暗色模式（双模式同精度，已确认）

- 卡片：`#2C2C2E` 底 / `#3A3A3C` 边（不用阴影，用边界高光）
- 分区线：`#3A3A3C`
- 时间徽章：底 25% 透明、字用原色
- 空状态线稿：`#48484A` 边框
- 其余沿用现有 DarkRemColors

## 9. 测试

- MainViewModel：toggleFlag 委托、flag 持久化（2 个新测试）
- TodoRepositoryImpl：setFlag 持久化（1 个新测试）
- DateParser：不变（quick-add 时间解析已有测试）
- 现有 50 测试保持全绿

## 10. 不做（明确排除）

- 键盘快捷键（用户指定）
- 拖拽排序 / 右键菜单 / 撤销
- 通知、重复规则（时间/旗标/完成时间仅做展示与存储，不触发系统行为）
- 移动端窄屏重设计（保持现状）
